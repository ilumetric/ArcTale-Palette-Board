## Индексы {#indexes}

Индексы общие для всего проекта: один индекс — один параметр во всех материалах и блюпринтах.

| Индекс | Параметр | Значение | Что делает |
|---|---|---|---|
| `0` | `PreviewMode` | `0`–`1` | Включает превью материала |
| `1` | `Emissive` | `0`–`1` и выше | Включает эмиссив материала. Значение больше `1` умножает силу эмиссива |

## Как подключить {#setup}

::: half В материале {#material}
- Создайте **Scalar Parameter** с именем из таблицы.
- В Details включите **Use Custom Primitive Data**.
- В **Primitive Data Index** укажите индекс из таблицы.
:::

::: half В блюпринте {#blueprint}
- В Details компонента меша найдите **Custom Primitive Data**, в массиве **Data** задайте элемент с индексом из таблицы. Если материал уже назначен, рядом с индексом видно имя параметра.
- Из графа: нода **Set Custom Primitive Data Float**, в **Data Index** — индекс из таблицы.
:::

::: card Правила {#rules}
- Индекс закреплён за параметром во всём проекте, под другое его не занимают. Значение задаётся на компоненте, и его читают все материалы этого меша.
- Имя параметра в материале — точно как в таблице.
- Новый параметр получает следующий свободный индекс и сначала добавляется в эту таблицу.
- Vector Parameter занимает четыре индекса подряд: указанный и три следующих.
:::
